# Brief: sell-the-dream-demo transcript

Same caveat as every run in this batch. Shape A (findings-recall): gold is
a **five-element scorecard plus a sequencing finding**, graded by
per-element agreement and whether the sequencing violation is caught —
same shape as `sandler`'s violation check, applied to Raskin's five
elements instead of the submarine's seven compartments.

## Situation

One call: a commercial insurance brokerage ("Thornfield Brokers") talking
to a rep about a risk-analytics platform. The rep pitches product
features almost immediately.

## Deliberate construction — the trap: individually-Covered elements, sequencing violation

- Rep opens with a feature pitch almost immediately: "our platform
  automatically flags underpriced policies using real-time claims data" —
  **element 4 (features) lands first**, before any of elements 1-3.
- Only *after* the feature pitch does the rep add: "the whole industry's
  shifting from annual reviews to continuous risk scoring" (element 1,
  backfilled) and "brokers who adapt now keep clients who'd otherwise
  shop around; the ones who don't lose accounts to firms who did"
  (element 2, backfilled).
- A brief, generic promised-land line appears near the end almost as an
  afterthought: "so basically you'd never get caught flat-footed on
  pricing again" (element 3, thin but present, and also backfilled after
  the pitch).
- Element 5 (evidence) is present: rep cites "a mid-size firm using this
  cut their claims leakage by 12% in the first two quarters."
- **The trap**: each of the five elements can individually be scored
  Covered or Partial if graded in isolation — the transcript technically
  contains all five ingredients. The sequencing check is what catches the
  real defect: elements 1-3 only appear *after* element 4, backfilled to
  sound strategic, not built up front. A shallow run that scores each
  element independently and stops there will miss this; the skill's own
  point is scoring order, not just presence.

## The trap a weak run fails

Scoring all five elements Covered/Partial based on presence alone and
either skipping the sequencing check or reporting "No violation found"
because every element technically appears somewhere in the call. The
correct read is a **sequencing violation** — the feature pitch preceded
elements 1-3, which is exactly the backfilled-vision pattern the skill
exists to catch, even though nothing is technically missing.

## Not present: reporting any of these is a hallucination

- No specific dollar figure for Thornfield's deal is stated anywhere.
- No named competitor or specific rival firm — "firms who did" and "firms
  who shop around" are generic, not named companies.
- The case-study firm is described only as "a mid-size firm," no name
  given — no company name should be invented for it.
