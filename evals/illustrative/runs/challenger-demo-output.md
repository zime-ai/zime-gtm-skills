## Single biggest missed teaching opportunity
Renata hands Josh a live reframe target — a board member pushing "why aren't we automating claims yet" — and Josh just parks it as context instead of teaching on it. The obvious reframe: automation bolted onto today's 18-day process just automates the bottleneck faster, same trap as hiring three more adjusters. He'd already made that exact argument for headcount one line earlier; he didn't carry it forward to the board's automation framing, so the buyer leaves the call still holding an unchallenged "maybe automation is the answer" belief.
