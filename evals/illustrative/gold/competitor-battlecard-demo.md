## Expected battlecard

### 1. Competitor named
RouteIQ. Quote: "we've also been looking at RouteIQ."

### 2. How the buyer framed them
Recommended by a peer company, positioned as cheaper for the same core
features. Quote: "A peer company recommended them, and they're apparently
a lot cheaper for the same core features."

### 3. What the buyer said RouteIQ does better/differently
- **Clear**: faster setup — "Their implementation team quoted a two-week
  setup, which is a lot faster than the multi-week timeline we've been
  discussing with you."
- **Tentative** (must stay hedged, not smoothed into a confident claim):
  no charge for API access — "I think I heard they don't charge for API
  access, but I'm not totally sure that's still true, might've been an
  old pricing page I saw."

### 4. What the rep countered with
Addressed the setup-timeline claim only: explained the vendor's timeline
includes a data-migration step likely not covered by RouteIQ's quote, and
offered to have the implementation lead confirm real scope directly.
Quote: "Our timeline includes a data-migration step for your historical
routing data — RouteIQ's quote likely doesn't cover that... I can have
our implementation lead get on a call with you directly."

### 5. Left unanswered
The API-access pricing claim — the rep acknowledged it ("Noted") but the
call moved to a different topic (decision-makers) immediately after, and
the rep never returned to it. Must appear here, not be dropped or folded
into section 4 as addressed.

## The trap a weak run fails

Either (a) stating the API-access claim as confident/unhedged instead of
tentative, or (b) marking it as addressed by the rep's nearby counter to
the setup-timeline claim, when that counter only ever responds to setup
timeline, never to API pricing.

## Not present: reporting any of these is a hallucination

- No dollar figure for RouteIQ's pricing anywhere on the call.
- No named RouteIQ contact — RouteIQ is discussed only secondhand by
  Owen.
- No real-world fact about any actual company named RouteIQ — everything
  must trace to what Owen said on this call.
