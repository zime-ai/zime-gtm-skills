# Generic stage ladder (fallback)

Used only when no `prep-note-config.md` exists yet in the working directory.
Written fresh for this repo — not copied from any company's internal
checklist. Generic on purpose so a first run produces a real note; the
interview (`config-interview.md`) replaces this with the user's actual stages.

For account-mode calls (no open deal — e.g. post-close, renewal, expansion),
use the Account Milestones table instead of a deal stage.

## Deal stages and exit criteria

| Stage | Exit criteria (source of the 3 moves) |
|---|---|
| Discovery | Pain confirmed as a real priority by the prospect, in their own words. A decision maker is named. Next step is scheduled. |
| Qualification | Budget range or authority confirmed. Timeline exists with a target date. Technical/legal fit has no known blocker. |
| Evaluation / POC | Success criteria are written down and agreed by both sides. An evaluation owner is named on the prospect side. A decision date is set. |
| Negotiation | Pricing is on the table with no open objection. Legal/security review is scheduled or cleared. The signer is named. |
| Closed | (No further moves — post-close calls should use Account Milestones instead.) |

## Account milestones (no open deal)

| Milestone | What "moved forward" looks like |
|---|---|
| Health | No unresolved complaint or unusual drop in usage since the last call. |
| Value | The customer states a concrete outcome or metric in their own words. |
| Expansion | A specific expansion path (more seats, a new team, a new use case) has a named owner and a date. |
| Renewal | Renewal timeline is known, and any blocker has a named owner. |

Pick the milestone closest to where the account already sits based on the
transcript(s); the 3 moves push that one forward, not all four at once.

## Attendee mode (no deal, no account context)

When neither a stage nor an account state is knowable, anchor the 3 moves on
the meeting title and whatever the attendees discussed last time: the single
most concrete next step those specific people were working toward.
