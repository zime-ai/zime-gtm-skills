# Mutual-action-plan rubric

Reuses `next-step-commitment`'s three-part test for what makes a commitment
real — a milestone in a mutual action plan is a next-step commitment with
a place on a timeline, not a different kind of thing. Don't invent a
second standard for the same idea.

## The three-part test (per milestone)

1. **Specific action** — not "follow up" or "circle back," a named thing.
2. **Date or concrete trigger** — a calendar date, or an event with an
   obvious, checkable occurrence. "Soon" or "before end of quarter" with
   nothing more specific fails this element.
3. **Two-sided ownership** — the prospect owns something too, not just the
   rep.

## Tagging a milestone

- **`heard`** — all three elements were actually stated on the call, or
  the milestone itself was stated as an agreed fact with both sides
  present. Quote what was said.
- **`inferred`** — the milestone is reasonable given what was discussed,
  but one or more of the three elements wasn't actually stated. Quote the
  closest thing said, and name which element(s) are missing (no date, no
  counterpart owner, or the action itself is a hand-wave like "we'll
  figure out procurement at some point").

A milestone missing a prospect-side owner entirely — only the rep has
anything to do — fails element 3 outright. Tag it `inferred` and say
plainly the plan is one-sided on that milestone; don't paper over it with
an owner that was never named.

## Reads-well-too check

If a milestone was clearly agreed to with a specific date and a named
owner on both sides, don't downgrade it to `inferred` over an overly
literal reading (e.g. "same time next week" counts as a date).

## All-inferred plans

If every milestone in the plan is `inferred`, that's not a mutual action
plan — it's a finding that the call never locked down real forward motion.
Say so explicitly rather than presenting a full-looking table that reads
as a real plan.
