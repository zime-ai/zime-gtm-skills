# BANT rubric

Four criteria, built for speed. This is a first-pass filter, not a deep
qualification — a call can score well here and still fail a later `meddicc`
pass once more stakeholders are involved.

## Budget

Any real signal on what this problem is worth solving, or what's currently
budgeted/planned for it — not necessarily an exact number, but more than "we
haven't thought about it." "We'd need to find budget" is Partial; "we have
roughly $40-60k set aside for this this year" is Covered.

## Authority

Is the person on the call the decision-maker, an influencer feeding a
decision-maker, or someone with no real path to a decision? Distinguish
these explicitly rather than assuming "in a call = has authority."

## Need

A specific problem the prospect described in their own words, not a
generic "we're always looking to improve." Look for a concrete pain, not
just interest in the category.

## Timeline

Is there a real reason this needs to be decided by a specific point — a
renewal, a budget cycle, a triggering event — or is "sometime this year"
the most specific thing said? Vague timelines are one of the most common
reasons an apparently-qualified deal goes quiet.

## Reads-well-too check

A first call that clearly surfaced strong signal on all four criteria should
not come back mostly Partial just because BANT is being applied strictly. If
that happens on a call that plainly went well, loosen what counts as
Covered before finalizing.
